Cooperative Multi-LLM
Reinforcement Learning

Cooperative Multi-LLM Reinforcement Learning is an open-source library for training multiple large language models to collaborate using multi-agent reinforcement learning. It provides implementations of various multi-agent reinforcement learning algorithms for language model collaboration and supports different environments and benchmarks.

About OpenMLRL

We are a group of researchers working on reinforcement learning for collaborative language model systems. Our work covers multi-agent reinforcement learning, preference learning, multi-turn interaction, and decentralized systems.

01

Cooperative learning

Training language model agents to coordinate their responses and solve tasks together.

02

Preference learning

Optimizing multi-LLM systems through pairwise preferences.

03

Multi-turn interaction

Improving multi-LLM system performance through multi-turn interaction with the environment.
